常见问题

关于 ForgeAgent，你可能想知道的

创建一个 Agent 需要多长时间？

通过对话式锻造，5 分钟即可完成一个基础 Agent 的创建。系统会自动解析你的需求，推荐合适的工具与规则模板，无需编写任何代码。复杂场景的深度调优可能需要额外 1-2 小时的迭代测试。

Agent 的行为是否安全可控？

完全可控。ForgeAgent 内置安全护栏机制，你可以为 Agent 设定行为边界、输出规则与敏感词过滤。每次 Agent 的工具调用、推理路径与输出结果均有完整日志，支持全链路追溯审计。

支持哪些工具和集成？

内置知识库检索、联网搜索、数据分析、文档生成等核心工具。企业版支持通过 RESTful API 对接企业内部系统（如 CRM、ERP、OA），也可自定义 Python/Node.js 工具插件，实现深度集成。

Agent 能同时处理多个任务吗？

可以。ForgeAgent 的 ReAct 推理引擎支持多步任务自动拆解与并行执行。Agent 会根据任务复杂度自主规划执行链路，串联多个工具调用，最终汇总结果交付。整个过程中 Agent 可自主处理异常与重试。

免费版和企业版有什么区别？

免费版可创建 3 个 Agent，每日 20 次对话，适合个人体验评估。个人版支持 50 个 Agent 与每日 200 次对话，解锁联网搜索与深度思考。企业版不限 Agent 数量与对话次数，支持私有化部署、API 集成与专属技术支持。
